# Navigating  
This is layouted out so that navigation should be easy but if you get stuck, this is a quick navigation guide.  

**Starting Point** are machine label as 'Very Easy' and, as the name suggests, should be the place where all new lab users should come to start HTB Labs.<br>
  
The include 3 different tiers:
### Teir 0 - Foundations
This teir teaches the basics of Offensive Security. It's main purpose to introducing connecting to HTB, Enumeration and using simple tools.

### Teir I - Fundamental Exploitation
This teir increased the difficulty and complexity a little by introducting basic exploitation techniques.

### Teir II - Multi-Step Attacks and Privilege Escalation
Being the most advanced teir of Starting Point, this teir will introduce to you some full-fledged machines that require multiple exploitation steps.  

**Main** are all machines from Retired to Active to Seasonal machines. Seasonal Machines become Active Machines when the season is finished. Active Machines become Retired Machines over time, HTB usually make a post on X which machine is becoming retired.
